# Contributing

Thank you for helping build an open evidence base on Caribbean literacy.

## Rules every contribution must meet
1. **Public sources only.** No student records, confidential institutional data or personal information.
2. **Provenance.** Source URL (https), publisher, reference year, retrieval date and licence for every value.
3. **No invented numbers.** No fabricated, interpolated or extrapolated statistics, and no demonstration data.
4. **Proxies are labelled.** Examination results are proxies, not literacy measures.
5. **Interpretations are checked.** Research records and analyses enter as drafts and are published once checked against their sources.

`node scripts/validate.mjs` must pass; CI runs it on every pull request.

## Ways to contribute
- Suggest a public dataset or study: open an issue with its link and licence.
- Report a data error: open an issue with the record id shown on the dashboard.
- Code: keep the site dependency-free and accessible (keyboard, screen reader, 360px screens).
