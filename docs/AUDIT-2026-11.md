# Audit note 1 — first pass (draft for review)

**Scope:** five World Bank WDI literacy series (data from UIS) for the 15 CARICOM member states. Retrieved 27 Nov 2026 via the World Bank API (most recent non-empty value per country, plus Jamaica youth-literacy history). Source last updated 11 Nov 2026.

## Findings
- **Youth literacy (15–24):** recent figure (2016 or later) for Belize, Guyana, Haiti, Jamaica, Suriname, Trinidad and Tobago. Older figures for Barbados (2012), Saint Lucia (2012), Grenada (1970), Saint Vincent and the Grenadines (1970). No figure for Antigua and Barbuda, The Bahamas, Dominica, Saint Kitts and Nevis. Montserrat is outside the series.
- **Adult literacy (15+):** recent figures only for Belize (2022), Guyana (2020) and Haiti (2017). Jamaica's latest is 1999; Trinidad and Tobago 1990; Barbados, Grenada and Saint Vincent 1970.
- **Jamaica:** youth literacy 93.57% (2022), up from 91.60% (1999). Female 99.30%, male 88.23%: a gap of about 11 points.
- **Consistency:** the published youth gender parity index for Jamaica (1.106, 2022) and Trinidad and Tobago (1.067, 2022) cannot be reproduced from the published female and male rates (1.125 and 1.120). Shown as published; to be queried with the source.
- **Estimates:** the API records do not say which values are UIS estimates. To check against UIS metadata.

## Limitations
- Values were transcribed from API responses; re-run the retrieval script to preserve byte-exact originals.
- These indicators are binary, largely self-reported, and say nothing about literacy in Caribbean Creole languages.
- Foundational reading, national assessments, examination results, digital and disability-disaggregated literacy are not yet audited.
